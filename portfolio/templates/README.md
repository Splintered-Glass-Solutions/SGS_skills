# Operating Templates

These templates make bounded AI work easier to delegate, resume, validate, and
close out.

- [Worker task packet](worker-task-packet.md): define scope, exclusions,
  acceptance criteria, and the expected evidence.
- [Worker closeout contract](worker-closeout-contract.md): return proof,
  blockers, remaining uncertainty, and next actions in a compact form.
- [Daily operating brief](daily-pm-brief.md): review active work, decisions,
  blockers, communications, and stale items without reconstructing the whole
  portfolio.

The templates are patterns, not a requirement to use a specific task tracker.
Replace `<agent-config>` and other placeholders with the conventions of the
target organization.
