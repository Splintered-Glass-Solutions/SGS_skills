# Skill Catalog

This catalog contains the generalized skills currently archived in the public
SGS resource library. Each entry links to its Codex-native `SKILL.md`.

## Plan and orient

- [`expansive-planning`](../skills/expansive-planning/SKILL.md): turn a broad request into a decision-ready implementation plan.
- [`interview-spec`](../skills/interview-spec/SKILL.md): discover the real goal, constraints, and acceptance criteria.
- [`prep-work`](../skills/prep-work/SKILL.md): check prerequisites and produce a safe run contract before substantial work.
- [`session-budget`](../skills/session-budget/SKILL.md): control scope, context, retries, and cost during long work.
- [`to-do-list`](../skills/to-do-list/SKILL.md): capture incoming work without prematurely executing it.
- [`to-do-list-planning`](../skills/to-do-list-planning/SKILL.md): convert bounded captured notes into an actionable batch brief.
