# Security and Sensitive Content

Do not open a public issue containing credentials, tokens, private URLs,
customer data, personal information, or raw production logs.

If you find sensitive content in this repository, stop sharing it, preserve
only the minimum location needed to identify the problem, and [contact SGS
privately](https://splinteredglass.solutions/contact). Include the affected
file or commit and a short description of the exposure. Do not include the
secret itself.

For ordinary workflow bugs or documentation improvements, use a normal issue
or pull request after removing private context.
